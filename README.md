# TicTacToe_new
A simple and interactive **Tic-Tac-Toe game** built using HTML, CSS, and JavaScript. It supports two-player gameplay with turn-based logic, win detection, draw handling, and a reset feature, along with sound effects for better user experience. The project is designed with clean and modular code and is **fully responsive using media queries**, ensuring smooth gameplay across different screen sizes and devices.
